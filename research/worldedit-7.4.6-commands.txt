## BiomeCommands
biomelist (biomels) -p <int>  -- Gets all biomes available.
    -p: Page number.
biomeinfo -t -p  -- Get the biome of the targeted block.
    -t: Use the block you are looking at.
    -p: Use the block you are currently in.
/setbiome <target:BiomeType> -p  -- Sets the biome of your current block or region.
    -p: Use your current position
/replacebiome <from:Mask> <target:BiomeType> -p  -- Replaces the biome of your current block or region.
    -p: Use your current position

## BrushCommands
none (unbind)   -- Unbind a bound brush from your current item
sphere (s) <pattern:Pattern> [radius:double=2] -h  -- Choose the sphere brush
    -h: Create hollow spheres instead
cylinder (cyl,c) <pattern:Pattern> [radius:double=2] [height:int=1] -h  -- Choose the cylinder brush
    -h: Create hollow cylinders instead
splatter (splat) <pattern:Pattern> [radius:double=2] [decay:int=1]  -- Choose the splatter brush
clipboard (copy) -a -v -o -e -b -m <Mask>  -- Choose the clipboard brush
    -a: Don't paste air from the clipboard
    -v: Include structure void blocks
    -o: Paste starting at the target location, instead of centering on it
    -e: Paste entities if available
    -b: Paste biomes if available
    -m: Skip blocks matching this mask in the clipboard
smooth [radius:double=2] [iterations:int=4] [mask:Mask=]  -- Choose the terrain softener brush
snowsmooth [radius:double=2] [iterations:int=4] -l <int> -m <Mask>  -- Choose the snow terrain softener brush
    -l: The number of snow blocks under snow
    -m: The mask of blocks to use for the heightmap
extinguish (ex) [radius:double=5]  -- Shortcut fire extinguisher brush
gravity (grav) [radius:double=5] -h <Integer>  -- Gravity brush, simulates the effect of gravity
    -h: Affect blocks between the given height, upwards and downwards, rather than the target location Y + radius
butcher (kill) [radius:double=5] -p -n -g -a -b -t -f -r -w  -- Butcher brush, kills mobs within a radius
    -p: Also kill pets
    -n: Also kill NPCs
    -g: Also kill golems
    -a: Also kill animals
    -b: Also kill ambient mobs
    -t: Also kill mobs with name tags
    -f: Also kill all friendly mobs (Applies the flags `-abgnpt`)
    -r: Also destroy armor stands
    -w: Also kill water mobs
heightmap <imageName:String> [radius:double=5] [intensity:double=5] -e -f -r  -- Heightmap brush, raises or lowers terrain using an image heightmap
    -e: Erase blocks instead of filling them
    -f: Don't change blocks above the selected height
    -r: Randomizes the brush's height slightly.
deform <shape:RegionFactory> [radius:double=5] [expression:String=y-=0.2] -r -o  -- Deform brush, applies an expression to an area
    -r: Use the game's coordinate origin
    -o: Use the placement position as the origin
set <shape:RegionFactory> [radius:double=5] <pattern:Pattern>  -- Set brush, sets all blocks in the area
forest <shape:RegionFactory> [radius:double=5] [density:double=20] <type:TreeType>  -- Forest brush, creates a forest in the area
feature <shape:RegionFactory> [radius:double=5] [density:double=5] <type:ConfiguredFeatureType>  -- Feature brush, paints Minecraft generation features
raise <shape:RegionFactory> [radius:double=5]  -- Raise brush, raise all blocks by one
lower <shape:RegionFactory> [radius:double=5]  -- Lower brush, lower all blocks by one
snow <shape:RegionFactory> [radius:double=5] -s  -- Snow brush, sets snow in the area
    -s: Whether to stack snow
biome <shape:RegionFactory> [radius:double=5] <biomeType:BiomeType> -c  -- Biome brush, sets biomes in the area
    -c: Whether to set the full column
morph [brushSize:double=5] [minErodeFaces:int=3] [numErodeIterations:int=1] [minDilateFaces:int=3] [numDilateIterations:int=1]  -- Morph brush, morphs blocks in the area
erode [brushSize:double=5]  -- Erode preset for morph brush, erodes blocks in the area
dilate [brushSize:double=5]  -- Dilate preset for morph brush, dilates blocks in the area

## ClipboardCommands
/copy -e -b -m <Mask>  -- Copy the selection to the clipboard
    -e: Also copy entities
    -b: Also copy biomes
    -m: Set the include mask, non-matching blocks become air
/cut [leavePattern:Pattern=air] -e -b -m <Mask>  -- Cut the selection to the clipboard
    -e: Also cut entities
    -b: Also copy biomes, source biomes are unaffected
    -m: Set the exclude mask, non-matching blocks become air
/paste -a -v -o -s -n -e -b -m <Mask>  -- Paste the clipboard's contents
    -a: Skip air blocks
    -v: Include structure void blocks
    -o: Paste at the original position
    -s: Select the region after pasting
    -n: No paste, select only. (Implies -s)
    -e: Paste entities if available
    -b: Paste biomes if available
    -m: Only paste blocks matching this mask
/rotate <rotateY:double> [rotateX:double=0] [rotateZ:double=0]  -- Rotate the contents of the clipboard
/flip (/mirror) [direction:BlockVector3=me]  -- Flip the contents of the clipboard across the origin
clearclipboard   -- Clear your clipboard
/revolve <pasteCount:int> -m <Mask> -r -e -b  -- Revolve the selection around a vertical axis
    -m: Set the source mask, non-matching blocks are not revolved
    -r: Perform revolutions in reverse (counter-clockwise)
    -e: Copy entities
    -b: Copy biomes
